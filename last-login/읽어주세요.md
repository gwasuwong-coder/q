# 마지막 접속 — 연무동 기록실

한국 인터넷 커뮤니티를 배경으로 한 독립 창작 검색 추리 게임입니다. 모든 인물·기관·사건은 허구입니다.

## 실행

폴더 안의 **index.html**을 Chrome 또는 Edge로 열면 됩니다. 파일을 더블클릭하거나 브라우저 창으로 끌어다 놓으세요. ZIP으로 받은 경우 먼저 전체 압축을 풀어주세요.

설치·서버·인터넷 연결·API 키가 필요 없습니다. 게임 데이터와 화면은 같은 폴더의 JavaScript와 CSS 파일에 있으므로 파일들을 함께 보관하세요. 브라우저 탭을 닫으면 게임의 실행도 끝납니다. 외부 폰트·영상·분석 추적·AI API를 사용하지 않습니다.

## 플레이

1. 의뢰 메일을 읽고 복구본을 엽니다.
2. 첫 화면의 공지·동네소식·장터 글과 댓글을 살펴봅니다.
3. 눈에 걸리는 이름, 물건, 장소를 검색합니다. 띄어쓰기와 일반 문장부호는 구분하지 않습니다.
4. 기록을 읽으면 연결된 자료의 접근 정보가 복구됩니다. 전에 검색한 단어를 다시 찾아보는 것도 방법입니다.
5. 중요한 글은 ‘증거 보관’으로 저장하고, 메모에 생각을 정리합니다.
6. 사건 보고서에서 세 가지 결론과 각 결론의 근거를 골라 제출합니다. 근거가 부족하면 수정 후 다시 제출할 수 있습니다.

읽는 속도와 도움 사용에 따라 약 15–20분을 목표로 만든 첫 사건입니다. 실제 플레이 시간은 아직 외부 플레이테스트로 검증하지 않았습니다. 침수 사고와 실종, 협박을 암시하는 내용이 있지만 점프스케어나 큰 소리는 없습니다.

## 저장

진행 상황과 메모는 브라우저의 localStorage에 자동 저장합니다. 같은 브라우저에서 같은 파일을 다시 여세요. 브라우저 설정, 시크릿 모드, 로컬 파일 정책 때문에 저장이 제한되면 메모 아래에 ‘현재 창에서만 유지’라고 표시합니다. 브라우저 데이터를 지우거나 파일 위치를 바꾸면 기존 저장을 불러오지 못할 수 있습니다.

## 포함된 것

- 원작 게임의 자산·문장·사건을 복제하지 않은 별도 세계관과 사건
- 검색 가능한 기록 22개, 댓글, 첨부파일 전사본
- 기록 접근 조건, 최근 검색, 증거함, 메모, 단계별 도움
- 근거를 확인하는 최종 보고서와 엔딩 1개
- 데스크톱·작은 화면에 맞춘 레이아웃

이 버전은 완결된 사건 하나를 담은 시제품입니다. Steam 연동, 업적, 여러 사건, 다국어, 실행파일 패키징은 아직 포함하지 않았습니다.
