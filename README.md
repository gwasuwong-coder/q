# LAST LOGIN — Case 01

어두운 1999년 탐정 사무소를 배경으로 한 고정 시점 조사 게임 프로토타입입니다.

## 핵심 조작
- **Q**: CRT 컴퓨터 쪽으로 시선 이동
- **E**: 사무실로 복귀
- **SPACE**: 의뢰인 대사 넘기기
- 컴퓨터에서는 아이콘 더블클릭으로 앱 실행

## 현재 구현
- Three.js 기반 3D 탐정 사무소
- 비 오는 창문, 깜빡이는 조명, CRT/스캔라인/노이즈 연출
- 검은 실루엣 의뢰인과 오프닝
- 사건 DB / 커뮤니티 게시판 / 삭제 자료 복구 / 증거함 / 메모장 / 사건 보고서
- 검색어 기반 단서 발견
- 읽은 기록 자동 증거 등록
- 최종 보고서 판정 및 엔딩
- LocalStorage 자동 저장
- WebAudio 기반 빗소리/전기음

## 실행
```bash
npm install
npm run dev
```
브라우저에서 Vite가 표시한 주소를 열면 됩니다.

## 빌드
```bash
npm run build
```

## 방향
특정 상용 게임의 자산이나 문구를 복제하지 않고, 오래된 PC 조사 인터페이스와 저해상도 호러 분위기에서 영감을 받은 독자적인 사건 조사 게임으로 확장하는 것을 목표로 합니다.
